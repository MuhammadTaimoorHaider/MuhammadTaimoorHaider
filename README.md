### How I approach a build

**Understand the workflow.** Start with the person using the system and the problem they need to solve.

**Connect the whole path.** Follow the request from the interface through the API, data, and model response.

**Make the result inspectable.** Show supporting sources where possible and keep model evaluation and limitations visible.
